Literasi Digital - Website WordPress

Website Literasi Digital merupakan proyek tugas mata kuliah Literasi Digital yang dibuat menggunakan WordPress.

Website ini bertujuan memberikan edukasi mengenai penggunaan teknologi dan internet secara bijak, aman, dan bertanggung jawab.

Teknologi

- WordPress
- PHP
- Apache (XAMPP)
- MariaDB
- Git dan GitHub

Struktur Database

Database website diekspor dan disimpan di:

"db/database.sql"

Cara Menjalankan

1. Instal XAMPP pada komputer.
2. Salin folder proyek ke "C:\xampp\htdocs\literasi".
3. Jalankan Apache dan MySQL melalui XAMPP Control Panel.
4. Buat database dengan nama "wp_literasi" melalui phpMyAdmin.
5. Impor file "db/database.sql" ke database tersebut.
6. Salin "wp-config-sample.php" menjadi "wp-config.php".
7. Sesuaikan nama database, username, dan password pada konfigurasi WordPress.
8. Buka browser dan akses:

"http://localhost/literasi"
